HARSHINI PORTFOLIO — QUICK START

Files:
- index.html: website structure and resume-based content
- style.css: responsive visual design and animations
- script.js: mobile menu, scroll progress, section reveals, active navigation, back-to-top

Run locally:
1. Extract the ZIP file.
2. Open the `harshini_portfolio` folder.
3. Double-click `index.html` to open it in Chrome/Edge.
4. For a better developer workflow, open the folder in VS Code and use the Live Server extension.

Notes:
- The page uses Google Fonts, so the font may fall back if you are offline.
- Contact links use the email, GitHub, and LinkedIn information in the supplied resume.
- Project cards are descriptive showcases; no project URLs were included in the resume, so no fake project links were added.
